# 实验一需求规格

版本：0.1。日期：2026-09-15。
依据：实验1需求分析与OpenCV环境基线详细指导书。
状态：需求与验收方案已编写；下述内容是待实现、待测试的约定，不是测试通过记录。

## 一 项目背景与范围

本项目面向需要处理动漫与图形素材的学生及课程实验人员，建立一个可重复运行的静态图像处理入口。用户通过命令行提供原始图片和输出路径，程序读取图片，检查尺寸、数据类型与通道，将符合约定的输入转换为灰度图并保存，同时报告处理状态与耗时。针对文件不存在、无法解码或输出失败等情况，程序应给出可理解的错误信息。项目保留原始素材，便于后续实验复用。本实验暂不实现特征匹配、三维重建、视频处理或图形界面，重点是完成稳定的基础流程及验证记录。

## 二 输入输出约定

- 输入：可解码的8位PNG/JPEG静态图像，数据类型为uint8；支持灰度、三通道BGR和四通道BGRA。16位等其他数据类型明确报错，本实验不做自动缩放。
- 路径：通过必填参数 --input 和 --output 传入；支持含中文和空格的合法Windows路径，命令中含空格的路径需加引号。
- 输出：单通道uint8 PNG，宽高与输入一致；要求输出扩展名为 .png，不区分大小写。
- Alpha：四通道输入舍弃Alpha后，将BGR转灰度；不与背景合成，完全透明位置仍按其存储的BGR计算。此约定需在运行信息中说明。
- 原图：不修改输入文件；输入、输出解析后的路径相同则拒绝处理；输出文件已存在也拒绝覆盖。
- 输出目录不存在时自动创建；目录或文件无法写入时明确报错。
- 成功：打印 SUCCESS，退出码0。失败：打印 ERROR及原因，退出码非0；不得误报成功。
- shape按(H,W)或(H,W,C)解释，像素索引为img[y,x]；OpenCV彩色通道为BGR，若以后用Matplotlib显示彩色图须转换为RGB。

计划运行形式（程序尚待实现）：

```powershell
& '..\.venv\Scripts\python.exe' '.\src\baseline_pipeline.py' --input '.\data\input\color.png' --output '.\data\output\color_gray.png'
```

## 三 功能需求

| 编号 | 需求 | 验证方法 |
|---|---|---|
| FR-01 | 接收必填的输入和输出命令行参数；不依赖写死的图片路径 | 更换参数处理不同图片；缺少参数时检查非0退出码 |
| FR-02 | 读取并校验输入，打印输入shape、dtype、通道数 | 用彩色、灰度、RGBA样本，对照实际数组属性 |
| FR-03 | 灰度输入保持像素值；BGR转灰度；BGRA按约定丢弃Alpha后转灰度 | 比较灰度输入与输出像素；将彩色转换结果与OpenCV参考计算比较 |
| FR-04 | 自动创建缺失输出目录，保存单通道PNG并检查保存结果 | 重新读取输出，检查shape、dtype及文件存在性；测试新目录和写入失败 |
| FR-05 | 打印输入输出路径、输出属性、处理耗时、状态与核心版本，提供退出码 | 捕获控制台输出，逐项检查；记录到evidence/output_info.txt |

## 五 异常需求

| 编号 | 触发条件 | 预期行为与验证方法 |
|---|---|---|
| EX-01 | 输入不存在、是目录或文件损坏无法解码 | ERROR说明读取问题，非0退出，不产生灰度结果；以不存在路径和伪造损坏文件验证 |
| EX-02 | 输入类型或通道不在约定内，或输出扩展名不是PNG | ERROR说明限制，非0退出；以16位PNG及.jpg输出参数验证 |
| EX-03 | 输出与输入相同、输出已存在、输出父路径被普通文件占用或无写入权限 | ERROR说明保存问题，非0退出，不覆盖已有文件；用临时测试文件与哈希验证，不改真实系统权限 |

## 六 业务用例

业务用例描述用户完成任务的过程；测试用例则选取具体文件和条件验证这些过程。

### UC-01 正常处理

前提：存在符合输入约定的彩色PNG；输出文件尚不存在。
步骤：用户传入两个路径；程序读取和检查、转灰度、保存并打印状态。
预期：输出同尺寸单通道uint8 PNG，SUCCESS，退出码0，原图未改变。
关联：FR-01至FR-05。

### UC-02 文件不存在

前提：输入路径指向不存在的文件。
步骤：用户运行同样的命令形式；程序发现读取条件不满足。
预期：ERROR包含失败原因，退出码非0，不生成结果图。
关联：EX-01、FR-05。

### UC-03 灰度输入

前提：输入为uint8灰度PNG。
步骤：程序按原始通道读取，识别二维数组，直接保存灰度数据。
预期：不按三通道访问；输出与输入的shape、dtype、像素值一致，退出码0。
关联：FR-02、FR-03、FR-04。

### UC-04 输出目录不存在

前提：输入有效，输出文件的父目录尚不存在且允许创建。
步骤：程序创建父目录，保存结果。
预期：目录和PNG生成，SUCCESS，退出码0；若无法创建则按EX-03报告。
关联：FR-04、EX-03。
