# 小组编码规范

## 1. 命名

- 函数使用 `snake_case`，例如 `run_sobel`
- 变量使用 `snake_case`，例如 `otsu_threshold`
- 常量使用全大写，例如 `RESULTS_DIR`
- 文件名使用小写字母和下划线

## 2. 注释

- 核心算法必须有简短注释
- 注释重点解释“为什么”，避免逐行翻译代码
- 函数使用 docstring 描述输入、输出和异常

## 3. 文件组织

- `src/`：源码
- `data/`：输入图片
- `results/`：程序输出
- `docs/`：设计与规范文档
- `report/`：实验报告

## 4. 单文件职责

`main.py` 负责本实验流程与算法函数，不在其中混入无关实验代码。

## 5. 图像处理规范

- 算法输入统一明确灰度/彩色状态
- 梯度计算使用浮点类型
- 保存前根据需要归一化到 0~255 并转换为 `uint8`
- 输出文件名能够体现实验内容和参数

## 6. 异常处理

- 图片读取失败必须显式报错
- 结果保存失败必须显式报错
- 对可能发生除零的计算进行保护

## 7. 可复现性

实验参数集中写在代码中，实验报告中记录最终使用的参数。
