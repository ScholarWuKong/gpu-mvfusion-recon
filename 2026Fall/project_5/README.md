# 实验五学习入口

本轮先学习前置知识，再逐步动手完成《实验五 角点检测与尺度空间》。材料面向已经接触过 Python 和图像读写、但尚未掌握特征值和尺度空间的学习者。

先读 [前置知识](01_前置知识.md)，再做 [自检与实验路线](02_自检与实验路线.md)。第一轮建议只学前置知识第 1～4 节，能解释“为什么边缘不等于角点”之后再继续。

这些文件是知识补充，不代表实验代码、实验结果或测试已经完成。原指导书保持不变。指导书中的 Git 命令是后续实验步骤，本轮没有执行提交、合并或推送。

建议学习顺序：

1. 图像数组与梯度：理解像素值怎样变化。
2. 窗口移动与特征值：理解怎样区分平坦、边缘、角点。
3. Harris 与 Shi-Tomasi：理解怎样给候选点打分。
4. 高斯模糊、金字塔与 DoG：理解为什么要在不同尺度观察。
5. 输入输出约定和 pytest：为后续实现做好准备。

对应指导书的六项任务：Harris 参数对比、Shi-Tomasi 对比、3～4 层金字塔、跨尺度差分与极值观察、至少 5 项单元测试、Git 分支开发。手写 Harris 是加分项。
