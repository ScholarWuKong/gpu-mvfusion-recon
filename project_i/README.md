# 增量式 SFM 项目

## 流程与模块

- 特征点匹配
- 特征点提取
- 求本质矩阵
- 相机位姿恢复
- 三角化
- BA

总体结构是一个增量式 SfM，所以我们才开始需要设计好增量式结构，数据流通，不同模块间的接口

## 项目框架

```text
project_i/
├── CMakeLists.txt
├── README.md
├── .gitignore
│
├── src/
├── include/
├── tests/
├── data/
├── docs/
└── third_party/
```

- `src/` 存放项目的主要源代码，包括 C++、CUDA 等实现文件。

- `include/`存放项目的头文件和接口声明。

- `tests/`存放项目的测试代码，用于验证各模块和功能是否正常。

- `data/`存放项目运行所需的输入数据，以及程序生成的输出数据。

- `docs/`存放项目相关文档，例如设计文档、实验记录、使用说明等。

- `third_party/`存放项目使用的第三方库或其他外部依赖。

- `CMakeLists.txt`项目的 CMake 构建配置文件，用于管理项目编译和依赖。

- `README.md`项目说明文档，包括项目介绍、目录结构、编译方法和使用说明等。

- `.gitignore`指定不需要提交到 Git 仓库的文件和目录，例如编译生成文件、临时文件等。
