# 固定标定内参的 GPU 稀疏点云覆盖改进

- 记录日期：2026-10-20。
- 目标：增强现有 SfM 稀疏点云的有效点数、图像覆盖与多视图支持；本轮不继续收紧重投影误差目标。
- 修改人：cc

## 标定参数

使用固定内参 `fx=3334.23, fy=3341.06, cx=2057.09, cy=1548.96`，无畸变。已确认 36 张输入图像均为 4096×3072，按 image1 至 image36 的数字顺序输入，过程中不缩放图像。

参数保存在 `configs/camera_vase.json`。新增 CLI `--intrinsics fx,fy,cx,cy`，完整保留不相等的 fx/fy 和非中心主点；与旧 `--focal` 互斥。BA 固定使用已标定内参。暂时关闭未知内参场景引入焦距自优化。

## 已实现的改动

1. **应用参数组织与标定输入**：将可独立检查的参数解析及相机选择移到 `include/app/application_options.h`、`src/app/application_options.cpp`，应用入口负责组合组件和执行流程。非法、缺失、非有限内参与冲突参数在创建 GPU 组件前被拒绝。
2. **GPU 空间覆盖**：`--gpu-feature-grid 8x6` 使 CUDA ORB 检测两倍候选，然后在已转换的关键点上按网格轮流保留响应较好的特征，最多保留设定预算；弱纹理但存在候选的网格有机会保留特征。空间选择在 CPU 执行，检测和描述子计算仍使用 OpenCV CUDA；这不是新增 CUDA kernel。
3. **描述子一致性**：新选择器同步复制对应描述子行并保留源顺序、图像 ID。没有改变后续 FeatureMatch 特征索引的数据契约。GPU 描述子缓存沿用原有完整内容一致性检查。
4. **GPU 前端可调配置**：显式增加 GPU 描述子预平滑开关、FAST 阈值选项；本轮增强配置使用 blur=on、FAST=10，基线仍为 blur=off、FAST=20。
5. **稳健三角化回退**：新增可选开关 `--robust-triangulation on`。先使用原有全视图 DLT；失败后按视线夹角排序，最多测试 64 个双视图假设，选择至少 60% 观测的一致集合，再以一致集合重估。仅将参与建点的几何内点启用，保留原始观测索引。此项只处理尚未建点的 Track，已有点重三角化/观测重激活仍未实现。
6. **可复现运行**：`scripts/run_calibrated_sfm.ps1` 从标定 JSON 读取参数、按数字排序输入、拒绝覆盖已有输出，并保存原始日志、完整命令参数与程序哈希。

全部覆盖选项默认关闭，原有无标定/单焦距与 CPU 特征路径继续可用。没有新增匹配后端、第三方依赖、演示入口或 CUDA 架构变更。

## 36 张输入的实际结果

全部运行使用 GPU ORB、CUDA Hamming 匹配、GPU BA，以及同一组固定内参，均注册 36/36 张、应用退出 0：

| 配置 | 点数 | 三视图及以上支持点 | 平均每图 32 px 覆盖格 | 平均误差 / px | RMS / px | 单次耗时 / s |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 标定基线，10k 特征 | 19,691 | 8,411 | 357.5 | 0.464 | 0.591 | 80.36 |
| 覆盖增强，10k 特征 | 24,601 | 9,937 | 425.7 | 0.497 | 0.630 | 106.98 |
| 覆盖增强，20k 特征 | 53,561 | 22,279 | 696.5 | 0.499 | 0.633 | 235.71 |

在相同 10k 特征预算下，增强配置得到 24,601 个点，相对基线增加约 25%；32 px 覆盖格增加约 19%。这证明改进并不完全来自提高特征数量，但本轮组合启用了多个选项，不能将收益单独归因于某一个开关。

20k 增强结果相对标定 10k 基线：点数增加 172.0%（约 2.72 倍），32 px 有效观测覆盖格增加 94.8%；三视图及以上支持点从 8,411 增至 22,279。平均重投影误差约 0.50 px，未为增点而放宽原有 4 px 外点阈值。

“覆盖格”把每张原始图像分成 32×32 像素网格，统计至少有一个启用且已关联三维点的观测所占格数，再对 36 张图取平均。它衡量图像中的有效观测分布，不是物体表面积完整率；背景不做人工裁除。64 px 指标及逐轮数据在 comparison.json 中。

运行存在时间重叠，耗时仅为单次墙钟参考，不是严格性能基准。

## 结果与预览

所有结果位于 `data/output/gpu_calibrated_20261020/`：

- `baseline_10k/`：19,691 点的标定基线。
- `coverage_10k/`：24,601 点的同预算增强结果。
- `coverage_20k/`：53,561 点的最终增强结果；含 `points.ply`、`points_colored.ply`、相机、观测、匹配、输入映射、标定副本、日志和完整运行参数。
- `point_cloud_comparison.png`：基线与增强结果的三视图主体取景对照。
- `point_cloud_comparison_full.png`：包含全部点范围的三视图对照。
- `image_coverage_comparison.png`：第 1、10、19、28 张原图上的有效观测位置，左基线、右增强。
- `comparison.json` 和各轮 `coverage_metrics.json`：机器可读统计。

彩色 PLY 对每点采用有效已注册观测对应的原图 RGB 中值；已逐点验证其 53,561 个 double 坐标与程序原始点云完全一致，没有增加、平滑或删除点。仍存在少量远离主体的离群点；主体预览通过坐标分位数取景，完整文件与全景预览均保留它们。

内嵌点云对照包含两轮全部点，预览坐标按范围量化为 16 位以控制体积，PLY 仍保留原始精度。基线/增强切换、旋转、缩放、主体/全景切换的脚本冒烟检查通过，未声称做了浏览器端性能基准。

## 实际验证

```powershell
cmake --build build --config RelWithDebInfo --parallel 4
ctest --test-dir build -C RelWithDebInfo --output-on-failure -V

.\scripts\run_calibrated_sfm.ps1 -outputDirectory data/output/gpu_calibrated_20261020/baseline_10k -featureCount 10000 -baseline
.\scripts\run_calibrated_sfm.ps1 -outputDirectory data/output/gpu_calibrated_20261020/coverage_10k -featureCount 10000
.\scripts\run_calibrated_sfm.ps1 -outputDirectory data/output/gpu_calibrated_20261020/coverage_20k -featureCount 20000
```

编译退出 0；CTest 1/1 通过。新增检查覆盖：四个标定参数的精确保留、旧 focal 行为、非法参数、空间均衡选择与描述子行对应、空特征 ID、包含一个错误视图的真实三角化调用、恢复 Track 后观测索引维护。原有 CPU/GPU 匹配、BA、三视图增量与回滚检查继续通过。

真实导出检查通过：每轮内参完全等于用户给定值、点坐标有限、每点至少两个有效注册视图支持、观测深度为正、有效观测重投影误差不超过原阈值、彩色点云坐标不变。

## 已知边界

本次改善了轮廓、纹理区域及若干薄弱视图的覆盖，但纯色区域没有可检测特征时仍可能留空。保持 SfM 范围，未增加 MVS 或插值补点。
